# Repository Automation Policy

This repository uses GitHub for source control only.

- Do not create, restore, enable, edit, or trigger GitHub Actions workflows.
- Do not add files under `.github/workflows/`.
- Do not configure CI/CD pipelines, automated builds, tests, releases, or registry publishing.
- Do not change GitHub Actions repository settings.
- Run tests locally when explicitly requested.
- Keep Git operations limited to ordinary source-control tasks (add, commit, pull, push) as directed by the repository owner.
- If an automated workflow appears necessary, request explicit approval before creating it.
